Diese eigenständige Testseite versucht, die exakt ausgewählte DB-Verbindung über ihre Freigabekennung auszulesen. Sie verändert pin2map nicht.

Ergebnis

Noch kein Test ausgeführt.

Hinweis: Die DB-Webschnittstelle ist undokumentiert. Insbesondere bei einer lokal geöffneten HTML-Datei kann der Browser den Abruf wegen CORS verhindern. Ein solcher Fehler bedeutet nicht, dass die Verbindungskennung ungültig ist. Es werden keine Daten an einen eigenen Server gesendet; Anfragen gehen direkt an bahn.de.
